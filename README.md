# Política de Privacidad - TotémBeta

**Última actualización: Noviembre 2026**

## 1. Información que Recopilamos

TotémBeta recopila información limitada necesaria para funcionar:

- Datos de uso de aplicaciones (nombre y tiempo de uso)
- Configuración de bloqueos y límites de tiempo
- Identificadores anónimos del dispositivo
- Preferencias de usuario

## 2. Cómo Usamos la Información

Usamos la información únicamente para:

- Proporcionar los servicios de control parental
- Mejorar la aplicación y su funcionalidad
- Enviar notificaciones sobre bloqueos y límites de tiempo
- Analizar estadísticas de uso de forma anónima

## 3. Almacenamiento de Datos

Todos los datos se almacenan localmente en tu dispositivo. No compartimos información con terceros sin tu consentimiento explícito. No vendemos ni alquilamos tus datos personales.

## 4. Seguridad

Protegemos tu información con encriptación estándar de iOS. Los datos se almacenan de forma segura utilizando las APIs de Keychain de Apple.

## 5. Permisos Solicitados

TotémBeta puede solicitar los siguientes permisos:

- **Acceso a aplicaciones**: Para monitorear y bloquear apps
- **Notificaciones**: Para alertas de bloqueo
- **Acceso a fotos** (opcional): Si integras captura de pantalla

## 6. Menores de Edad

Si la app es utilizada por menores, un adulto responsable debe dar consentimiento parental. Los datos de menores se tratan con la máxima confidencialidad.

## 7. Cambios en esta Política

Podemos actualizar esta política ocasionalmente. Te notificaremos de cambios significativos a través de la app.
